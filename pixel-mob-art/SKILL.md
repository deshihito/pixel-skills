# ドット絵ルールブック（pixel-mob-art）

一対一ドット絵訓練（2026-11-17〜）で得た学びを、対象に依存しないルールとして整理したもの。新しい学びは「事例」としてではなく、既存ルールの追加・修正としてここに入れる。

使い方: 描く前に P（手順）と R1〜R3 を決め、描きながら R4〜R10 を適用し、納品前に末尾のチェックリストで全項目を照合する。ルール同士が衝突したら、番号の小さいルールを優先する。

---

## P. 制作手順

- **P1 コードでピクセルを置く。** AI画像生成で描かない。Pillow等で座標を指定して描き、パレットと形を完全に制御できる状態を保つ。
- **P2 基準サイズは32×32。** 16では判別が潰れる。縮小が要る用途でも、まず32で形を確定させてから縮小する。
- **P3 色数は透過含め10色前後まで。** ベタ塗り基調。階調は素材ごとに「主色・明・暗」の3階調を基本とする。
- **P4 納品前に必ず自分で目視し、悪い案は自分で却下して作り直す。** 捨てた案は理由つきで報告する。自分の弱点は納品時に先に言う。
- **P5 納品形式:** 3面シート（透過チェッカー／想定される実地背景／暗背景）＋256px拡大（ニアレストネイバー）＋32px原寸ファイル。1点ずつ納品し、量産しない。

## R1. 対象の捉え方

- **R1-1 対象を「そのもの」として描く。記号化・キャラ化しない。** 生物なら生物として、物なら物として描く。可愛いデフォルメ、笑顔・口・頬・キラキラ等のマスコット装飾で誤魔化さない。
  - 判定: 装飾を全部消しても対象として読めるか。読めなければ形が不足している。
- **R1-2 物理的な「型」を1つ決めてから描き、型を混ぜない。** 型とは「その対象がどういう物理でその形になっているか」（例: 地面に張り付くドロドロ型／丸く固まる型／浮遊型／立位型）。型が曖昧だと輪郭が角ばり、何だか分からなくなる。
  - 判定: 型を一文で言えるか。シルエットの全ての部分がその型で説明できるか。

## R2. シルエット

- **R2-1 黒一色のシルエットだけで対象が判別できる形にする。** 提示前にシルエットだけを描いて確認する。判別できなければ色や内部表現では救えない。
- **R2-2 大きな面を直線で切らない。** 上部を直線の斜面にすると「山」等別の物に見える。主形は曲線のプロファイルで作る。
- **R2-3 非対称は下部・付属部で付け、上部の主形は安定させる。** 全体を対称にすると作り物に見え、全体を崩すと形が壊れる。
- **R2-5 体軸を水平にしない。** 胴の背・腹のラインを地面と平行な直線の組にすると、生物ではなく「台」に見える。前後の高低差（例: 肩が高く腰が低い）と曲線で体軸を持たせる。腹のラインも背に合わせて傾け、後方では絞り上げる。
- **R2-4 対象の「格」は姿勢で出す。** 威厳・強さは首や背の反り（S字の曲線）と頭の位置で作る: 頭を高く保ち、わずかに前へ突き出す。首や背を棒状の直線で引くと格が消える（#009ドラゴンの指摘）。逆に丸く縮こまった姿勢は弱さ・可愛さになる。描く前に「この対象の格はどの姿勢か」を決める。

## R3. 部品の形

- **R3-1 部品を均一な幅・真っ直ぐな輪郭で作らない（長方形禁止）。** 均一幅の棒や、上下を直線で挟んだカプセル形は「長方形の部品」に見えて雑になる。各部品に太さ・輪郭のプロファイルを持たせる。
  - 例（柄）: 握り端は太く（コブ）、中間は細く、付け根で膨らむ。
  - 例（胴体）: 肩の盛り上がり、背の緩い凹み、腹の下がり、首のくびれ。
- **R3-2 輪郭の変化は疎な制御点＋補間の滑らかな弧で作る。** 列ごとに小刻みに上下させるとウニョウニョした輪郭になり、実在感が消える。1pxの段差は数列かけて移行する。
  - R3-1とR3-2はセット: 「変化は付けるが、滑らかに」。
- **R3-3 模様は中実の不定形で描く。** 斑点等を輪だけで描くと記号・花模様に読まれる。
- **R3-4 描く前に比率表を作る。** 全長を基準に、頭・首・胴・尾・脚などの配分をpx実測値で決めてから描く。比率は対象の構造から取る（四足なら胴の深さと脚の長さの関係、首の長さは胴との対比、等）。描いた後にバウンディングボックスと各部の実測で比率表と照合する。比率を決めずに描くと、どこかが必ず均一・水平に流れる。
- **R3-5 同じ種類の部品を均一にしない。** 脚・棘・指・歯などを全部同じ長さ・太さ・角度で描かない。構造上の理由がある差を付ける（前脚と後脚、付け根側と先端側、荷重のかかる側とそうでない側）。

## R4. 輪郭（アウトライン）

- **R4-1 アウトライン必須。** 純黒ではなく対象色寄りの濃色で全周を囲う。輪郭がないと背景に溶けて形が崩れる。
- **R4-2 輪郭の付け方（色・太さ・有無）は全体で統一する。** 一部だけ縁取りが違うと「不揃い」になる。
- **R4-3 全体を1つのシルエット（マスク）として描き、内部構造は後から彫る。** 部品ごとに下敷きの輪郭を引くと隙間が埋まって塊になる。単一マスクなら輪郭は自動で統一される（R4-2の実装方法）。
- **R4-4 穴・窪みは矩形で描かない。** 角を落とした楕円にし、下側の内壁に中間色を置いて奥行きを出す。真っ黒な四角はシールに見える。

## R5. 陰影と光

- **R5-1 陰影は形に沿わせる。** 「その列の底からの深さ」等、形の構造から陰を決める。全面を直線の帯で切らない。接地面・下部に濃色が溜まるのが基本。
- **R5-2 ハイライトは光源側の斜面に「塊」で置く。** 点描で散らさない。頂点に被せると「雪帽子」化して別の物に見える。
- **R5-3 光源は全体で1つに統一する。** 部品ごとに光の向きが違うと貼り合わせに見える。

## R6. 色と素材

- **R6-1 素材ごとにパレットを分け、境界をはっきりさせる。** 1つの対象に複数素材がある場合（木の柄＋鉄の頭など）、素材の境目が一目で分かること。
- **R6-2 金属には「照り」を入れる。** 面の明暗だけでは金属に見えない。刃や弧の外周に沿って、純白に近い反射を「線」で1本走らせる。面で塗らない。
- **R6-3 木目は線で示す。** 面に沿った線1〜2本。ドットの散らし模様にしない。
- **R6-4 刃先・切断部は最も明るい帯で示す。** 機能部位は明度で読ませる。

## R7. 目・感覚器・内部表現

- **R7-1 目は明確に読める形で描く。** 正面なら左右に離した対、横向きなら見える側に1つ（解剖学的に正しい側）。目を消す・点に潰すのは不可。
- **R7-2 目にはサイズの下限がある。** 横向きでも2×3px程度＋反射1pxが目安。1pxの目は点にしかならない。
- **R7-3 内部構造（核・臓器・模様）は目に誤読されない形にする。** 「楕円＋中央ハイライト」は瞳＋反射に読まれる。内部構造は位置を目から離し（下部等）、横長に潰し、コントラストを弱め、ハイライトを付けない。
- **R7-4 表情付けは最小限。** 口は描かないのが基準。形と目で読ませる。

## R8. 接続部・付属部・脚

- **R8-1 付属部は本体と同じシルエット（マスク）に含めて描く。** 後から別パスで足すと、境界に本体の輪郭線が走って「分離して」見える。付け根は本体の陰影色で溶かし、輪郭は全体の外周だけに付ける。
- **R8-2 脚・支持部は構造の位置に付ける。** 等間隔に並べない（前脚は肩の真下、後脚は腰の真下）。付け根には腿等の膨らみを持たせる。
- **R8-3 脚を棒にしない。** 上部太く下へテーパーさせる。接地部は対象の構造まで描く（偶蹄なら幅＋割れ目、鳥なら地面のライン上に趾を連続させる。趾を点々と離すとゴミに見える）。
- **R8-4 奥側の付属部は短く・暗く・内側に寄せる。** 手前との重なりと明暗で奥行きを作る。
- **R8-5 脚は前後で構造と長さを変える。** 四足の後脚は腿→脛の関節の折れを持ち、前脚より複雑で、長さも違う。前後とも同じ長さの直柱で描くと「テーブル」になる（#009ドラゴンの指摘）。体軸が傾いていれば、接地線が1本でも脚の長さは均一にならないのが正しい。

## R9. 配置

- **R9-1 余白があるなら中央揃えにする。** 描画範囲（バウンディングボックス）の中心をキャンバス中心に合わせる。特に接地型は下に寄りがちなので縦位置を必ず測る。
- **R9-2 モーションのフレーム間では基準フレームと同じずらし量を使う。** フレームごとに中央化すると再生時に位置がブレる。

## R10. 人工物・道具

- **R10-1 道具は斜めに描く**（柄が左下、頭が右上）。スロット等の小さい表示で一目で読めることが目的。
- **R10-2 柄と頭（本体と作用部）は同じ座標系で設計する。** 本体の軸とそれに直交する軸で作用部を組み、作用部の中心は軸線上に置く。一部だけ正面を向かせると向きが揃わず、重心が軸からずれると不釣り合いになる。
- **R10-3 作用部は機能の形にする。** 斧頭なら楔形（上辺は真っ直ぐ、刃側で広がり、下辺は付け根へ斜めに上がる）。上下両辺を膨らませると丸い盾・団扇に化ける。ピッケル頭なら弧＋両端の尖り（太さは中央でも3px程度、光の帯は上端1px）。
- **R10-4 柄の断面は円柱として陰影を付ける**（縁・中央・縁の3階調）。平らな板に見せない。太さは対象との釣り合いで決める（ピッケルの柄は軸3px前後が基準作の実測）。

## R11. モーション

- **R11-1 モーションは同じ絵の微変形で作る。** 基準絵＋2枚（潰れ／伸び）で生きてる感じを出す。接地点は固定し、上部と目を±1pxずらす。
- **R11-2 変形は型の物理と一致させる。** 潰れでは体積が横へ逃げ、伸びでは付属部が引っ込む。
- **R11-3 ループ順は 基準→潰れ→基準→伸び、1フレーム約320ms目安。**

## 納品前チェックリストと細部スコア

描き終えたら全項目を照合し、1つでも外れたら直してから納品する。さらに下の細部スコアで自己採点し、**合計18/22以上、かつ型・シルエット・比率に0がない**ことを納品の条件とする。スコアは納品時に申告する。

細部スコア（各0=未達 / 1=部分的 / 2=達成）:

| 項目 | 見るルール |
|---|---|
| 型 | R1-2 |
| シルエット | R2-1 |
| 姿勢・体軸 | R2-4, R2-5 |
| 比率（実測と比率表の一致） | R3-4 |
| 部品の形 | R3-1, R3-2, R3-5 |
| 輪郭 | R4 |
| 陰影 | R5 |
| 素材 | R6 |
| 目・誤読 | R7 |
| 接続・脚 | R8 |
| 配置 | R9 |

- [ ] 型を一文で言えるか。その型で全部分を説明できるか（R1-2）
- [ ] シルエットだけで対象が判別できるか（R2-1）
- [ ] 直線で切った大きな面がないか（R2-2）
- [ ] 均一幅・長方形の部品がないか（R3-1）
- [ ] 輪郭がウニョウニョしていないか（R3-2）
- [ ] 輪郭が全周・統一された付け方になっているか（R4-1, R4-2）
- [ ] 穴が矩形になっていないか（R4-4）
- [ ] 陰影が形に沿っているか。ハイライトが塊で光源側にあるか（R5-1, R5-2）
- [ ] 素材の境界が読めるか。金属に照りの線があるか（R6-1, R6-2）
- [ ] 目が読める大きさか。内部構造が目に誤読されないか（R7-1, R7-2, R7-3）
- [ ] 付属部が本体と同一シルエットで描かれ、分離して見えないか（R8-1）
- [ ] 脚が棒でなく、構造の位置に付いているか（R8-2, R8-3）
- [ ] 中央揃えになっているか（実測したか）（R9-1）
- [ ] 人工物の場合、全部品の向きが同じ軸系で揃っているか（R10-2）
